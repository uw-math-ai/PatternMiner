# E072 root preflight

2026-09-21, before the sole pilot execution. This is author/root review,
NOT independent review and not approval of a mathematical theorem.

Checked: all ordinary targets restore (5,nu) of degree fifteen; the ambient
plethysm uses the untruncated routine, not the degree-ten helper. The full
old sixteen-origin cube is recovered using its frozen direct survivor
predicate. Equal-shaped D4/F objects remain separate. Square origins carry
their actual two-cell payloads. Positive candidates retain all four-cell
words, rather than selecting a preferred filling as a training label.

The added corner's entry 1 in scoring features is a proxy for a separate
one-box product factor, not an asserted LR tableau on the combined skew
diagram. It is never used as an exact witness. Candidate validity comes
from the positive LR family and a separate brute-force word check.

Training minimizes excess colliding sources, with no global repair.
Same-output candidate graphs are complete bipartite: a successful global
assignment would therefore certify only sufficient capacity and provide
a finite lookup. It cannot establish the value of learning. Held-out
origins may have been seen, while whole output shapes are withheld from
training. Small sample size, prior symbolic exposure, lexicographic ties
and a possibly stalled coordinate optimizer must be disclosed.

All three seeds/configurations, splits and baseline families are fixed
before execution. Selection uses validation, never test. Feature ablation
selection uses validation only. A failure stops promotion, not reporting.
Full finite inverse/lookup tests do not prove a natural all-parameter rule.

The experiment is CPU-only integer search within the existing cumulative
caps. No new files are added to frozen src, no prior artifact is edited,
and no upload, network, model API or installation is performed. New runner
syntax was parsed without importing or executing scientific code. Output
directory is required absent and the ledger rejects a reused run ID.

Decision: proceed with the bounded exploratory pilot, with independent
code/result review still pending regardless of numerical outcome.
