ordinary.csv contains 4,096 ordinary labeled homogeneous triples in ranks five/six. development.csv contains 1,024 additional triples per rank drawn among triples passing the symmetric Bruhat and contiguous-interval inversion inequalities. Permutations are in one-line notation. Depth is zero for a positive; for a zero it is the minimum number of retained dimensions witnessing an empty generic intersection. A common starting example has u=14235, v=24153, w=45123 and depth two. python3 can import the supplied oracle module (lrcalc underlies it). Call oracle.coefficient(u,v,w), oracle.empty(u,v,w,retained), oracle.depth(u,v,w), and oracle.usage(). Inputs may be integer tuples or lists. Ranks 2 through 9 are available. A distinct exact coefficient question or retained-subset emptiness question costs one unit, shared across processes via the persistent ledger. A repeated identical query is free. depth() charges its underlying questions. Supply homogeneous triples. Standard numerical Python, SciPy, NumPy and SageMath are installed. Each session has the same initial data. The nonemptiness convention in empty() sorts each of the three top intersection factors within the blocks between retained dimensions, then checks for a Schubert product term below the dual of the third minimal representative in Bruhat order.
